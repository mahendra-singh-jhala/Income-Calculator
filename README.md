# 💰 Income & Expense Calculator (Frontend)

A simple and responsive **web-based income and expense calculator** that helps users estimate their monthly or yearly income and manage their expenses — all directly in the browser using **LocalStorage**. No backend required.

## 🌟 Features

- **Add & Track Income**
  - Enter multiple income sources.
  - Support for monthly or yearly income calculation.

- **Expense Management**
  - Add, edit, or delete expenses.
  - Automatically updates totals in real time.

- **Dashboard Overview**
  - View total income, total expenses, and remaining balance.
  - Visual summary of financial progress.

- **LocalStorage Support**
  - Data is stored in the browser, so users' inputs are saved even after page reloads.

- **Responsive UI**
  - Works on desktop, tablet, and mobile devices.

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **LocalStorage**

## 🚀 Getting Started

## Installation

1. **Clone the repository:**

```bash
 git clone https://github.com/mahendra-singh-jhala/Income-Calculator
```

2. **Install dependencies**

```bash
 npm install
```

3. **Run the frontend**

```bash
 npm start
```
